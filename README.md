# 🎨 Real-Time Multi-Color Detection using OpenCV

A real-time computer vision project that detects and identifies multiple colors from a live camera feed using Python and OpenCV.

## 🚀 Features

- 📷 Real-time camera/video stream
- 🎨 Multi-color detection
- 🔵 Blue detection
- 🟢 Green detection
- 🔴 Red detection
- 🟡 Yellow detection
- 🟣 Additional color detection
- 📦 Bounding boxes around detected objects
- 📍 Displays object center coordinates
- 🔢 Counts detected objects
- ⚡ Real-time processing using OpenCV

## 🛠️ Technologies Used

- Python
- OpenCV
- NumPy
- Computer Vision
- HSV Color Space
